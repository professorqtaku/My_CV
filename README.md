# HTML & CSS Resume

This project is a simple resume website built using only **HTML** and **CSS**.  
The main purpose of the project is to **learn and understand the fundamentals of HTML structure and CSS layout, styling, and positioning**.

The focus is on:
- Semantic HTML elements
- Basic CSS styling
- Layout techniques (Flexbox / Grid)
- Building a clean and readable resume layout

No frameworks or JavaScript are used, keeping the project lightweight and easy to understand.
